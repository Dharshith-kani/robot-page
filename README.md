# Next Human Interface

A responsive, animation-led landing page built with plain HTML, CSS, and JavaScript.

## Color system
- Obsidian Black: `#080808`
- Chrome Silver: `#CDCBCA`
- Laser Crimson Red: `#D41514`

## Included
- Hero title reveals in sequence: THE NEXT → HUMAN → INTERFACE
- Robot image reveals after the heading
- Scroll-triggered section and image reveals
- Subtle hero pointer movement on desktop
- Responsive mobile navigation
- Reduced-motion accessibility support
- All seven supplied robot images (no external image assets)

## Run locally
Open `index.html` in a browser. For a local development server, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

The design follows the cinematic, editorial pacing of the supplied reference video while using the provided NHI imagery and color palette.
